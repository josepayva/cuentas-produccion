Política de privacidad de Cuentas

Última actualización: 23 de noviembre de 2026 · eMotion Studios

Cuentas es una aplicación de uso personal de eMotion Studios para llevar la cobranza, los gastos y los rodajes de sus trabajos de producción audiovisual. No es un servicio abierto al público.

Qué datos guarda

  • Los trabajos, clientes, artistas, pagos, gastos y ajustes que el propio usuario registra.
  • El correo con el que el usuario inicia sesión.
  • Si el usuario conecta Google Calendar, un permiso (token) de Google que permite crear, actualizar y borrar los eventos de rodaje y entrega que la propia app genera, y consultar la lista de calendarios para elegir dónde guardarlos.

Cómo usa los datos de Google

La app solo usa el acceso a Google Calendar para crear, cambiar y eliminar los eventos de los trabajos que el usuario registra, en el calendario que el usuario elige, y para mostrar la lista de sus calendarios. No lee ni guarda otros eventos, no comparte los datos de Google con terceros y no los usa para publicidad ni para entrenar modelos. El uso de la información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde se guardan

Los datos se guardan en una base de datos de Supabase (región São Paulo), protegida para que cada cuenta solo pueda ver sus propios datos. El permiso de Google se guarda en el servidor y nunca se envía al navegador.

Cómo borrar los datos

El usuario puede desconectar Google Calendar en cualquier momento desde Ajustes → “Desconectar”, lo que revoca y borra el permiso. También puede quitar el acceso desde myaccount.google.com/permissions. Para borrar todos los datos de la cuenta, escribe a jozeph9@gmail.com.
